# Employee-Raise-Issue-ServiceNow

Employee Raise Issue is a ServiceNow ITSM project that allows employees to report issues easily through a Record Producer and Service Portal.
It uses a custom application, tables, UI Policies, and widgets to collect, organize, and manage employee-raised issues.

Platform: ServiceNow
Project Type: IT Service Management (ITSM)

1. Project Objectives

The main objective of this project is to provide employees with a simple and user-friendly way to raise their issues through a ServiceNow Service Portal.

Simplify Issue Reporting: Allow employees to submit their issues through a centralized Service Portal.

Create a Custom Application: Develop a custom ServiceNow application to manage employee-raised issues.

Organize Issue Details: Store issue information such as requester name, short description, category, subcategory, priority, description, and state in a custom table.

Use a Record Producer: Create a user-friendly form that allows employees to submit issues without directly accessing the backend table.

Implement UI Policies: Control field visibility, mandatory status, and read-only behavior based on defined conditions.

Configure Field Dependencies: Make subcategory options depend on the selected category to improve data accuracy.

Develop a Service Portal: Provide a simple interface where employees can access the issue submission form.
